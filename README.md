# InaZurivors

Fangame gratuito y no oficial, roguelite de supervivencia inspirado en Inazuma Eleven. Proyecto de distribución: se genera desde el proyecto local con `tools/distribucion.py`, no se edita a mano.

Inazuma Eleven, sus personajes, nombres, diseños, logotipos y música son propiedad de LEVEL-5 y/o sus respectivos titulares. Este proyecto no está afiliado, patrocinado ni aprobado por LEVEL-5.
